# Личный кабинет абонента ТКО — Frontend

Проект разработан по техническому заданию работодателя. Реализует интерфейс авторизации, регистрации и базовую структуру личного кабинета абонента ТКО с интеграцией с backend API.

---

## 📌 Реализованные требования ТЗ
### По макету

Реализованы следующие страницы:

- Страница авторизации (вход в систему)
- Страница регистрации абонента
- Главная страница (личный кабинет пользователя)

### По функционалу
#### 1. Регистрация пользователя

Реализована форма регистрации с обязательными полями:

- ИНН
- Название организации
- КПП
- Email
- Номер телефона
- Captcha

**Поведение формы**

- При вводе ИНН выполняется автоматический поиск организации через API.
- Название организации может подставляться автоматически.
- Кнопка отправки регистрации доступна только при заполнении обязательных полей.
- Используется серверная captcha.
- Есть возможность обновить captcha.
- После успешной регистрации пользователь может перейти к авторизации.

**API интеграция:**
```POST /users/register```

#### 2. Страница входа

**Страница входа содержит:**

* Поле ввода, где можно указать:

- ИНН
- Email
- номер телефона
  
* Поле ввода пароля.
* Кнопку входа.
* Переход к регистрации.
* Кнопку восстановления пароля (временно не реализовано).

**Авторизация выполняется через:**

```POST /users/login```


После успешного входа пользователь попадает в личный кабинет.

#### 3. Главная страница (личный кабинет)

После входа пользователь видит:
- Информацию о договоре
- Название организации
- Основные действия в виде кнопок:

Доступные разделы:
- Заявка на дополнительные услуги
- Документооборот
- Начисление оплаты
- Информация о договорах
- Чат со специалистом

(часть разделов пока реализована как макет интерфейса).

**4. Заявка на дополнительные услуги**

Реализована форма выбора услуги:

Пользователь может:
- выбрать тип услуги из списка
- указать адрес оказания услуги
- вернуться в личный кабинет

**Форма подготовлена для дальнейшей интеграции с API.**

🔗 Работа с API

Проект использует backend API для:
- поиска организации по ИНН
- получения captcha
- регистрации пользователей
- авторизации

**Базовый URL API задаётся в коде:**

```const API_BASE_URL = 'http://<backend-address>/api';```

## 🚀 Запуск проекта
### Установка зависимостей
```npm run install```
или
```npm run i```
### Запуск локального сервера
```npm run start```

После запуска проект будет доступен в браузере по адресу, указанному в консоли.
